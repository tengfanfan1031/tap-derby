# 搖搖賽馬 Tap Derby

團隊聚餐用的分枱賽馬遊戲。每張枱是一匹馬，全場同事用手機狂按螢幕，按得愈快，自己那枱的馬就跑得愈快。電視顯示跑道、現場評述和名次。介面中英文同屏顯示（中文在上，English 細字在下）。

**開始玩：** https://tengfanfan1031.github.io/tap-derby/

## 當晚流程

1. 用接駁電視的電腦開啟上面的連結，揀枱數（預設 5 張枱，適合 40–50 人），按 **在電視開房**。之後可以把電腦上的網址（`?host=1`）存成書籤，下次一打開就直接開房。
2. 電視首頁會顯示一個大 QR Code，以及每張枱的人數卡。同事先自己掃 QR Code，輸入名字（可以不填），再按自己的枱，例如 **第 1 枱**、**第 2 枱**。電視即時顯示每枱人數和名字。
3. 主持人等齊人之後，按 **開始比賽**。電視倒數 3 秒，全場一齊開跑；跑道旁仍有細 QR Code，方便遲到的同事加入。
4. 同事狂按手機上的大掣。馬匹按**每枱的平均手速**前進，所以人少的枱也一樣公平。
5. 所有枱衝線後自動完場，電視顯示冠、亞、季軍、時間，以及「全場最快手指」前 5 名；每部手機也會顯示自己那枱的名次。
6. 按 **再跑一場** 可以馬上開始下一場，同事不用重新掃描。

整晚都要讓電視電腦保持開著這個頁面，因為它就是房主。

## 每枱專屬 QR Code（可選）

房間代碼會記在電視電腦上，重新整理或重新開房都會沿用同一個代碼，所以可以預先為每張枱印一張 QR Code。在網址後面加上 `&t=枱號`，同事掃描後就會自動入枱：

- 第 1 枱：`https://tengfanfan1031.github.io/tap-derby/?room=代碼&t=1`
- 第 2 枱：`https://tengfanfan1031.github.io/tap-derby/?room=代碼&t=2`

## 主持人按鈕

| 按鈕 | 作用 |
|---|---|
| 開始比賽／再跑一場 | 倒數 3 秒後開跑 |
| 提早完場 | 比賽太長時，按目前位置排名次 |
| 重設 | 回到等待開跑狀態 |
| 全螢幕 | 投影時隱藏瀏覽器工具列 |

## 小貼士

- 每人每秒最多計 16 下，用連點程式也不能無限加速。
- 一個房間最多 120 人。
- 一般手速下，大約 20 秒跑完一場。

## 技術

只有一個 `index.html`，不需要伺服器或帳號。多人連線使用 [PeerJS](https://peerjs.com/)（WebRTC）：每部手機直接連到電視電腦，比賽邏輯和名次都在電視上計算。

`local-server/` 是沒有互聯網時的後備版本：用 Node.js 在電腦上運行伺服器，同事連同一個 Wi-Fi 就可以玩（執行 `node local-server/server.js`）。
